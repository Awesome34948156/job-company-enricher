Job Company Enricher

Company enrichment on job postings — HK listing status, size, reputation.

API keys

A lookup costs one DeepSeek call plus three Serper queries (five in deep mode). The Serper free tier is 2,500 queries, so roughly 830 lookups.

The base URL is editable so a proxy can be slotted in later.

Behaviour

Cache

Listing codes and dates are immutable, so they're cached for a year. But “not listed” is only cached for 14 days — a company can IPO later.

CompanyAgeHitsStale groups

Limits

Usage today, against the daily budget. Counters reset at local midnight.

HKEX dataset

Used to verify a proposed stock code against the exchange's own name for that code. It carries codes and names only — no listing dates or boards — so those are always shown only when an HKEX source is cited.

Diagnostics

Security

API keys are stored unencrypted in this browser profile. Any extension or person with access to this profile can read them. This extension is designed for personal, local use.

Publishing it in this form to the Chrome Web Store would expose your keys to anyone who installs it. A public release requires a backend proxy that holds the keys server-side and authenticates users — this is not something that can be fixed client-side, since a key shipped to a client is a key given away.

Keys are stored in chrome.storage.local and never in chrome.storage.sync, so they are not replicated to other Chrome profiles signed into the same account.

The company name and job title you view do leave your browser — they are sent to Serper and DeepSeek. That is the unavoidable cost of the feature.
